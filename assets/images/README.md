## Tips for Best Results
1. Keep file sizes under 350 KB per image using JPEG (85% quality) or WebP.
2. Ensure subjects are centered so natural responsive cropping maintains good framing on mobile viewports.
3. Keep the file names exactly as shown above so the website picks them up automatically without code changes.
